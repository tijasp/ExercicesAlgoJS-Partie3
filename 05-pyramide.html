#05 - Pyramide

Le but est de dessiner, pour un nombre n acquis auprès de l'utilisateur, la pyramide suivante :

1
2 2
3 3 3
...
n n n ... n (autant de fois que la valeur de n)

 

Quelques remarques pour réaliser le code :

  • Rien n'interdit aux boucles for d'être imbriquées !
  • L'affichage peut se faire ligne par ligne dans la console (solution recommandée).
    Cependant, si vous souhaitez utiliser la fonction alert() pour faire l'affichage, il faut construire une seule string dans laquelle les lignes de la pyramide sont séparées par le caractère '\n'.
