#06 - Le nombre secret

Le but est de construire le jeu du nombre secret.

Un nombre entre 0 et 100 est choisi aléatoirement par le programme.
Par des propositions successives, le joueur doit trouver ce nombre. À chaque coup de jeu le programme indique si le nombre proposé est trop grand ou trop petit.
Le programme indique "Victoire !" lorque le nombre secret est trouvé.

 

Quelques remarques pour réaliser le code :

  • Le nombre secret est généré dès le chargement de la page ; celui-ci devra être accessible/visible depuis la fonction de rappel play().
  • Les informations communiquées au joueur ("Trop grand", "Trop petit" ou "Victoire !") pourront se faire à l'aide le la fonction alert().
  • Bonus : Tous les contrôles réalisés sur le nombre saisi pour gagner en robutesse de code (c'est bien un nombre ? un nombre entier ? entre 0 et 100 ?) seront les bienvenus.
